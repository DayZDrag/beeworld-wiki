# BeeWorldSite — документация

Obsidian-хранилище документации BeeWorld Wiki. Основное описание находится в `PROJECT.md`, журнал — в `CHANGELOG.md`, а структурированные задачи — в `STRUCTURED_IDEAS.md`. Вики использует только очищенные реальные скриншоты игры, жёлто-медовую игровую палитру и публикуется как статическая версия из `dist/`.

Открытая опубликованная версия: https://dayzdrag.github.io/beeworld-wiki/

Для всех публичных и локальных ссылок используются только нейтральные адреса без личных данных.
