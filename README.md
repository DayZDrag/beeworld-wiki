# BeeWorldSite

**BeeWorld Wiki** — интерактивная русскоязычная вики по текущему прототипу BeeWorld. Она содержит статьи о мире, ульях, ресурсах, существах, мутациях, управлении и сохранениях. Готовая статическая версия находится в папке `dist/`.

## Открытие

Откройте `dist/index.html` в браузере. Для локального сервера из папки проекта можно выполнить:

```powershell
python -m http.server 4173 --directory dist
```

После этого сайт будет доступен по адресу `http://localhost:4173`.

## Состав

- `dist/index.html` — разметка сайта;
- `dist/assets/site.css` — адаптивный визуальный стиль;
- `dist/assets/app.js` — переключение статей, поиск по вики, оглавление активной статьи и мобильное меню;
- `dist/assets/beeworld-overworld.png` — игровой образ внешней карты с ульями и роем;
- `dist/assets/beeworld-hive-interior.png` — игровой образ внутренности улья с сотами;
- `BeeWorldSite_obsidian/` — Obsidian-хранилище с документацией проекта.

Оригинальная атмосферная иллюстрация `beeworld-meadow.png` сохранена как ранний материал и не используется в текущей версии страницы.

## Как пользоваться вики

- Выберите тему в левом меню или на стартовой статье.
- Введите запрос в поиске; клавиша `/` сразу ставит курсор в поле.
- На телефоне откройте список разделов кнопкой с тремя линиями в шапке.
